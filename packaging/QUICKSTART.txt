FHIR cohort synth
================

Input
-----
A file or folder containing a FHIR R4 (4.0.1) export in UTF-8 JSON.
- .json: one FHIR resource or Bundle.
- .ndjson/.jsonl: one complete resource per line.
- Gzip (.gz) files and subfolders are supported.
Include patients and linked resources, keeping their original IDs and references.

Run from the package folder
---------------------------
Windows x64 (PowerShell):
  .\fhir-cohort-synth.exe run --input "C:\FHIR export" --output "C:\FHIR output"

Linux x64 (glibc 2.35+):
  ./fhir-cohort-synth run --input "/data/FHIR export" --output "/data/FHIR output"

Replace the paths above. The output folder must be new and outside the input.
Progress appears in the terminal. Wait for the final completion message.

Output
------
  result/fhir/       Perturbed FHIR files
  result/reports/    Reports
  intermediates/     Databases and processing state
